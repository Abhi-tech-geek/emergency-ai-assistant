🧠 AI Emergency First Response Assistant

An AI-powered emergency response assistant that provides instant first-aid guidance during medical emergencies.

This tool analyzes emergency situations and delivers clear, life-saving instructions in seconds.

🚨 Problem

During emergencies, people panic and don't know what to do before help arrives.

This assistant helps by:

Identifying the emergency

Providing immediate first aid steps

Guiding users until professional help arrives

⚡ Features

✅ AI-powered emergency detection
✅ Instant first aid instructions
✅ Works offline with fallback rules
✅ Fast API backend
✅ Mobile-friendly UI
✅ Safe & secure (API keys protected)

📦 Installation
1️⃣ Clone the repo
git clone (https://github.com/Abhi-tech-geek/emergency-ai-assistant)
cd emergency-ai-assistant

2️⃣ Create virtual environment
python -m venv venv
venv\Scripts\activate   # Windows

3️⃣ Install dependencies
pip install -r requirements.txt

4️⃣ Add API key

Create .env file:

GROQ_API_KEY=your_api_key_here

5️⃣ Run backend
uvicorn Backend.app:app --reload

6️⃣ Open frontend

Open in browser:

Frontend/index.html

bike accident bleeding heavily

Identify emergency

Provide first aid steps
